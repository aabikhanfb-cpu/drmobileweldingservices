# Dr Mobile Welding Services — Website

Responsive React + Vite website prepared for GitHub and Vercel.

## Pages
- / — Home
- /services — Services
- /about — About
- /service-areas — Service areas
- /contact — Contact and quote request

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Vercel
Import this repository. Use build command `npm run build` and output directory `dist`.
